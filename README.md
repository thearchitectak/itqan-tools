# أدوات إتقان — ITQAN Tools

منصة مجانية مفتوحة المصدر تجمع:

- **أدوات PDF** على غرار iLovePDF: دمج، تقسيم، حذف صفحات، استخراج صفحات، ترتيب الصفحات بالسحب والإفلات، ضغط، تدوير، علامة مائية، ترقيم الصفحات، توقيع.
- **التحويل**: الصور ← PDF، PDF ← صور، وورد ← PDF، PDF ← وورد، إكسل ← PDF، PDF ← إكسل.
- **رموز QR دائمة مدى الحياة**: روابط، نصوص، Wi-Fi، واتساب، اتصال، رسائل، بريد، بطاقة تواصل، موقع جغرافي، مع ألوان وشعار وتنزيل PNG و SVG و JPG.
- **الباركود الخطي**: EAN-13 و EAN-8 و UPC و Code 128 و Code 39 و ITF-14 وغيرها.
- **دراسة الجدوى بالذكاء الاصطناعي**: أسئلة أساسية وفرعية، وبحث في أحدث بيانات السوق، ونموذج مالي محسوب برمجيًا، وتنزيل الدراسة بصيغة Word والنموذج المالي بصيغة Excel بمعادلات حية.
- **لوحة تحكم للمالك وحده**: تعديل هوية الموقع، تفعيل الأدوات وإيقافها وإعادة تسميتها وترتيبها، إضافة خدمات جديدة دون برمجة، تعديل أسئلة دراسة الجدوى، اختيار مزوّد الذكاء الاصطناعي، النسخ الاحتياطي.

## لماذا رموز QR هنا دائمة؟

الرموز «ثابتة» (Static): تُكتب البيانات داخل الرمز نفسه، فلا تمر بأي خادم وسيط، ولا يمكن أن تتوقف أو تنتهي صلاحيتها، حتى لو أُغلق الموقع. (المواقع التي تبيع اشتراكات تستخدم رموزًا «ديناميكية» تمر عبر خوادمها، فتتوقف عند انتهاء الاشتراك.)

## الخصوصية

جميع أدوات PDF والصور والمستندات تعمل **داخل متصفح المستخدم**؛ فلا تُرفع الملفات إلى أي خادم، ولا توجد تكلفة معالجة عليك مهما زاد عدد المستخدمين. دراسة الجدوى وحدها ترسل إجابات المستخدم إلى مزوّد الذكاء الاصطناعي.

## النشر على Cloudflare Pages (مجانًا)

### 1) ارفع الكود إلى GitHub
أنشئ مستودعًا عامًا (Public) باسم `itqan-tools` وارفع إليه محتويات هذا المجلد. ملف `.gitignore` يمنع رفع الأسرار.

### 2) أنشئ المشروع في Cloudflare
1. من لوحة Cloudflare: **Workers & Pages ← Create ← Pages ← Connect to Git** واختر المستودع.
2. إعدادات البناء: **Framework preset:** None — **Build command:** اتركه فارغًا — **Build output directory:** `public`.
3. اضغط **Save and Deploy**.

### 3) أنشئ مخزن الإعدادات (KV)
1. **Storage & Databases ← KV ← Create** باسم `ITQAN_KV`.
2. في مشروع Pages: **Settings ← Bindings ← Add ← KV namespace**، واجعل اسم المتغير `ITQAN_KV` واختر المخزن الذي أنشأته.

> ملف `wrangler.example.toml` مرجعي فقط ولا يُستخدم في النشر عبر GitHub. لا تغيّر اسمه إلى `wrangler.toml`، وإلا أصبحت إعدادات Cloudflare تُقرأ منه بدل لوحة التحكم.

### 4) أضف المتغيرات السرية
في **Settings ← Variables and Secrets ← Add** أضف المتغيرات التالية مع اختيار **Encrypt**:

| المتغير | الوصف |
|---|---|
| `ADMIN_PASSWORD` | كلمة مرور لوحة التحكم (قوية وطويلة) — **إلزامي** |
| `ADMIN_USERNAME` | اسم مستخدم للوحة التحكم — اختياري ويُنصح به |
| `SESSION_SECRET` | نص عشوائي طويل (40 حرفًا أو أكثر) لتوقيع جلسات الدخول |
| `ANTHROPIC_API_KEY` | مفتاح Claude من console.anthropic.com (المزوّد الافتراضي) |
| `GEMINI_API_KEY` | مفتاح Gemini من aistudio.google.com — بديل اختياري |
| `OPENAI_API_KEY` | مفتاح OpenAI — بديل اختياري |

يكفي مفتاح مزوّد واحد، ثم تختاره من لوحة التحكم. بعد إضافة المتغيرات أعد النشر (**Deployments ← Retry deployment**).

### 5) ادخل لوحة التحكم
افتح `https://اسم-موقعك.pages.dev/admin` وسجّل الدخول. لا يملك أحد غيرك صلاحية الدخول، لأن كلمة المرور محفوظة في أسرار Cloudflare وليست في الكود المنشور على GitHub. بعد خمس محاولات دخول خاطئة يُقفل الدخول من العنوان نفسه مدة 15 دقيقة.

### 6) اربط نطاقك
من **Custom domains** في مشروع Pages أضف نطاقك الخاص.

## إضافة أدوات وخدمات جديدة

- **دون برمجة** — من لوحة التحكم ← «الخدمات الإضافية»: أضف رابطًا لخدمة خارجية، أو صفحة كاملة بكود HTML و JavaScript تعمل داخل الموقع في إطار معزول.
- **أداة مدمجة جديدة** — أضف تعريفها إلى `BUILTIN_TOOLS` في `public/assets/js/defaults.js`، ثم أضف تنفيذها في `public/assets/js/pdf-tools.js` (أو ملف جديد)، وارفع التعديل إلى GitHub فيُنشر تلقائيًا.

## بنية المشروع

```
public/                  الواجهة (موقع ثابت)
  index.html             الصفحة الرئيسية وجميع الأدوات
  admin/index.html       لوحة التحكم
  assets/js/
    defaults.js          الإعدادات الافتراضية وقائمة الأدوات وأسئلة دراسة الجدوى
    pdf-tools.js         أدوات PDF والتحويل
    codes.js             رموز QR والباركود
    feasibility.js       نموذج أسئلة دراسة الجدوى وعرض النتيجة
    finance.js           النموذج المالي (NPV و IRR وفترة الاسترداد ونقطة التعادل)
    feas-export.js       إنشاء ملفي Word و Excel
    admin.js             لوحة التحكم
  vendor/                المكتبات المستخدمة (محلية، دون الاعتماد على أي CDN)
functions/               واجهة الخادم (Cloudflare Pages Functions)
  api/config.js          إعدادات الموقع العامة
  api/feasibility.js     إعداد دراسة الجدوى عبر الذكاء الاصطناعي
  api/admin/*.js         دخول المالك وحفظ الإعدادات
```

## التشغيل المحلي

```bash
npm install
cp .dev.vars.example .dev.vars   # ثم عدّل القيم
npm run dev                      # http://localhost:8788
```

لتجربة دراسة الجدوى محليًا دون مفتاح، أضف `AI_MOCK=1` إلى `.dev.vars` فيعيد الخادم بيانات تجريبية ثابتة. لا تضف هذا المتغير في Cloudflare.

## حدود معروفة

- تحويل وورد ← PDF يدعم صيغة DOCX فقط، وقد يختلف التنسيق في المستندات المعقدة. الوضع المباشر يُنتج صفحات مصوّرة، ووضع «نافذة الطباعة» يُنتج نصًا قابلًا للتحديد.
- تحويل PDF ← وورد/إكسل يستخرج النصوص والجداول البسيطة؛ الملفات الممسوحة ضوئيًا تحتاج إلى وضع «مطابق للشكل الأصلي».
- الضغط القوي يحوّل الصفحات إلى صور؛ ولذلك يحتفظ الموقع تلقائيًا بالنسخة الأصغر حجمًا.
- أرقام دراسة الجدوى تقديرية، ويُنصح بمراجعتها مع مختص قبل الاستثمار.
